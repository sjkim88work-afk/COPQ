# 실패비용(COPQ) 관리 프로그램 — 범용판

제조 현장의 불량 실적을 **부품 BOM × 단가**로 금액화하고, 귀책 판정·재검·재사용·클레임까지 반영해
실패비용(손실 확정/잠재, REWORK, 예방비용, 클레임)을 공정별 한도와 함께 관리하는 Streamlit 프로그램입니다.
공정·부품·불량유형·선택 목록·통화·주차 기준을 모두 설정할 수 있어 어느 사업장·제품에도 쓸 수 있습니다.

## 1. 설치 · 실행

필요: Python 3.10 이상 (Windows · macOS · Linux 공통)

- **Windows**: `run_windows.bat` 더블클릭 (처음 한 번은 패키지 설치로 1~2분 소요)
- **macOS**: `run_mac.command` 더블클릭 (처음 한 번은 패키지 설치로 1~2분 소요)
  - Python 3이 없으면 [python.org](https://www.python.org/downloads/macos/)에서 설치
  - “확인되지 않은 개발자” 경고가 뜨면 파일을 **우클릭 → 열기 → 열기**
  - 그래도 열리지 않으면 터미널에서 한 번만: `xattr -dr com.apple.quarantine 폴더경로` 후 `chmod +x run_mac.command`
- **Linux / 직접 실행**: `./run.sh` 또는 `pip install -r requirements.txt` → `streamlit run app.py`
- **사내 공유**(서버 PC 1대에서 실행, 다른 PC는 브라우저로 접속):
  `streamlit run app.py --server.address 0.0.0.0 --server.port 8501` → `http://서버IP:8501`
  (SQLite 파일 기반이라 동시 입력자가 수 명 수준일 때 적합)

## 2. 처음 시작하기

빈 데이터셋으로 열면 **시작하기** 화면이 나옵니다. 네 가지 중 하나를 고르세요.

1. **직접 설정** — 회사명, 공정 목록, 통화, 주차 기준만 입력하고 시작 → 기준정보에서 부품단가 → 불량유형 → BOM → 목표 순으로 등록
2. **표준 엑셀 양식** — 양식을 받아 시트별로 작성 후 한 번에 업로드 (빨간 머리글 = 필수 열)
3. **체험용 샘플 데이터** — 가상의 모터 조립 라인 6개월치로 기능 둘러보기
4. **기존 ECV VER_9.x 엑셀 이관** — ‘ECV 실패비용 SYSTEM’ 엑셀을 쓰던 곳은 그대로 이관

## 3. 데이터셋 (사업장 · 제품 · 고객사별 분리)

`data` 폴더의 `.db` 파일 하나가 데이터셋 하나입니다. 사이드바에서 전환하고,
**데이터 관리 › 데이터셋**에서 새로 만들거나(현재 기준정보 복사 가능) 삭제합니다.
다른 PC로 옮길 때는 `.db` 파일만 복사하거나, **전체 데이터 내보내기(표준 양식)** 엑셀을 가져오면 됩니다.

## 4. 표준 양식 시트

| 시트 | 내용 | 필수 열 |
|---|---|---|
| 설정 | 회사명·시스템명·통화·주차기준(sun/mon)·선택 목록 | 항목, 값 |
| 공정 | 공정/라인 목록과 표시 순서 | 공정명 |
| 부품단가 | 실패 시 손실되는 부품(원가 요소) 단가 | 부품명, 단가 |
| 불량유형 | 비용구분(실패/예방/제외), 원인분류, 처리방안, 불량상태 등 | 불량유형, 공정 |
| BOM | 불량 1건당 손실 부품과 수량 | 불량유형, 부품명, 사용수량 |
| 일일불량 | 발생 실적 (제외=1 이면 집계 제외) | 날짜, 공정, 불량유형, 수량 |
| 귀책판정 | 주차 단위 판정·재검·재사용·클레임 | 연, 월, 주차, 공정, 불량유형 |
| 목표 | 공정별 연간 한도·월간 목표 | 연도, 공정, 연간목표 |
| 조치내역 | 개선 조치 이력 | 연, 불량유형 |

가져오기 방식: **교체**(시트 단위 통째 교체) / **추가**(일일불량·조치는 추가, 나머지는 같은 키 갱신).
일일불량에만 있는 공정·불량유형은 자동 등록되고, 참조 오류는 경고로 알려 줍니다.

## 5. 화면 구성

| 메뉴 | 내용 |
|---|---|
| KPI 대시보드 | 공정별 연간 한도 사용률, 월별 추이(확정/보류·목표선·클레임), 한도 초과·페이스 경보, NCR별 클레임 |
| 월간 파레토 | 공정별 월간 목표 대비, 유형별 파레토(손실/추정/수량), 월간 클레임 발행, 진행 중 조치 |
| 일일 불량 입력 | 공정 선택 → 유형 목록에 수량만 입력. 조회·수정·삭제, 건별 제외, 엑셀 일괄 업로드 |
| 귀책 판정 | 확정원인, 귀책(사내/공급), 재검불량/합격, 재사용/보류, NCR, 클레임 정보 |
| 클레임 관리 | 클레임 원장, NCR 일괄 청구(클레임No·분담률·협의완료일), 업체별 회수율 |
| 월간 조치내역 | 원인분석·조치·진행상태·담당·완료예정 |
| 기준정보 | 공정·라인, 부품단가(변경 이력), BOM, 불량유형, 손실단가(자동), 목표, **설정** |
| 데이터 관리 | 데이터 검증, 분석 보고서·전체 데이터 내보내기, 가져오기, 데이터셋, 백업·변경 이력 |

**기준정보 › 설정**에서 바꿀 수 있는 것: 회사·시스템명, 통화 단위, 주차 기준, 원인분류·처리방안·불량상태·확정원인·조치상태 목록,
귀책 판정 대상(원인분류/처리방안). 계산에 쓰이는 값(비용구분 실패/예방/제외, 귀책 사내/공급, 재사용/보류)은 고정입니다.

## 6. 계산 로직

- 손실단가 = Σ(BOM 사용수량 × 부품단가)
- 집계 키 = 연|월|주차|공정|불량유형 (비용구분 ‘제외’ 유형과 ‘제외’ 체크 건은 제외)
- 폐기금액 = (수량 − 귀책수량 − 재사용수량 − 재사용보류) × 단가
- REWORK = 재검합격 중 ‘재사용’ × 단가 · 손실(잠재) = 재검합격 중 ‘보류’ × 단가
- 클레임 = 귀책수량 × 단가 · 예방비용 = 비용구분 ‘예방’의 추정손실
- 손실(확정) = 예방이 아닌 건의 폐기금액 · 손실비용 = 확정 + 잠재
- 검증: 클레임 + 예방 + REWORK + 잠재 + 확정 = 추정손실
- 클레임: 클레임No 입력 시 청구완료, 분담률 = 실청구액 ÷ 청구금액, 조정액 = 청구금액 − 실청구액

## 7. 파일 구성

```
app.py         화면
engine.py      계산 엔진
db.py          저장소(SQLite)·설정·데이터셋
excel_io.py    표준 양식·VER_9.x 이관·보고서·샘플 데이터
data/          데이터셋(.db), data/backups 자동 백업
```

환경변수 `COPQ_DATA`로 데이터 폴더 위치를 바꿀 수 있습니다(예: 공유 드라이브).
